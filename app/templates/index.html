About This Project

Bachelor Thesis 2026

My name is Hățăgan Maria-Christiana and I've developed my thesis project on helping further researches on how important is the preprocessing of scanned mammographies. Many romanian towns have dealed with the problem of lack of medical staff and modern equipment, and this is a problem that can be partially solved by the help of AI. The main goal of this project is to help at first with the preprocessing of handscaned mammographies, and then to create a detection system that can be used for further research on the topic of breast cancer mass detection.

Technology Stack
  • Deep Learning: YOLOv8 (Ultralytics)
  • Dataset: CBIS-DDSM Mammography Database
  • Preprocessing: 5 methods (Gaussian+CLAHE, Otsu+NLM, etc.)
  • Backend: Flask + OpenCV + NumPy
  • Frontend: Bootstrap 5 + Chart.js
Model Performance

Best performing model: CC+MLO View with Test method

  • mAP50: 0.4484
  • Precision: 0.4750
  • Recall: 0.4806

This is a research project for educational purposes. Not intended for clinical diagnosis.
